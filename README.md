# 🎟️ e-Ticket

Um projeto simples em **HTML, CSS e JavaScript** que simula a compra de ingressos online.  
O usuário pode escolher o tipo de ingresso, definir a quantidade desejada e verificar a disponibilidade em tempo real.  
Ao efetuar a compra, o estoque do ingresso é atualizado automaticamente.

---

## 🚀 Funcionalidades
- Seleção do tipo de ingresso: **Pista**, **Cadeira Superior** e **Cadeira Inferior**.   
- Validação para impedir compras com quantidade inválida.  
- Estoque dinâmico que diminui a cada compra confirmada.  
- Mensagens de alerta para sucesso ou falha na compra (quando não há ingressos suficientes).  

---

## 🛠️ Tecnologias utilizadas
- **HTML5**  
- **CSS3**  
- **JavaScript (Vanilla JS)**  

---

## 🚀 Possíveis Melhorias

- Permitir cancelar compras (devolver ingressos ao estoque).
- Adicionar preço e cálculo automático do valor total da compra.
- Criar um histórico de compras na mesma sessão.
- Conectar a um backend para controle real de vendas.
